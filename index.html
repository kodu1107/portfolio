01 FMCW 종합설계 · 2025

FMCW 레이다 기반
차량 식별 및 추적

보행자 안전을 위해 레이다 Raw Data에서 객체의 거리·속도·특징을 추출하고, 접근 차량 경고로 연결했습니다.

내 기여
MATLAB 신호 분석, PSD 기반 식별과 Kalman Filter 적용
팀 결과
수집 → 분류 → 추적 → 경고 시스템 구현, 후속 논문으로 확장
  • MATLAB
  • FFT · PSD
  • Kalman Filter
후속 논문과 결과 보기 ↗
프로젝트 과정 자세히 보기 ＋

문제와 설계 판단

보행자 안전과 직결되는 경고 시스템에서는 오판의 원인을 추적할 수 있는 판단 근거가 중요하다고 생각했습니다. 또한 제한된 연산 자원에서의 활용과 응답 시간을 고려해, Doppler 성분과 PSD 등 물리적으로 해석할 수 있는 신호 특징 기반 식별을 선택했습니다. MATLAB에서 센서 입력부터 접근 경고까지 연결해 동작을 확인했습니다.

개인 기여와 검증

Raw Data의 Doppler 성분을 분석하고 PSD 특징을 식별에 반영했습니다. Kalman Filter를 결합해 탐지 이력을 안정화하고 MATLAB에서 결과를 비교했습니다. 실험 결과를 바탕으로 필터링과 추적 조건을 보완하며 후속 연구로 발전시켰습니다.

AWR1843BOOST
레이다 측정→DCA1000EVM
Raw IQ 수집→FFT · PSD
거리·속도·식별→Kalman Filter
추적 · 접근 경고

02 안테나 설계 · 2024

5.8GHz 배열 안테나
설계 및 측정

5.8GHz 배열 안테나에 DGS를 적용하고, 제작 후 공진 주파수 차이를 설계 조건과 제작 오차의 관점에서 분석했습니다.

내 기여
ADS 안테나 설계·시뮬레이션, 실측 비교와 모델 재검토
검증 결과
실측 6.28GHz에 대해 조건 반영 모델 6.25GHz 확인
  • ADS
  • Patch Array
  • DGS
설계와 실측 비교 자세히 보기 ＋

설계 → 제작 → 분석

배열 안테나의 이득 향상을 위해 DGS 구조를 비교했습니다. 공진 주파수가 예상과 달라 식각 오차, DGS 정렬, 시뮬레이션 설정을 검토하고 수정 조건으로 다시 계산했습니다.

검증의 범위

실측과 모델의 차이를 설명하는 데 집중했습니다. 제작 공차를 반영한 모델에서 실측 공진 주파수와 가까운 결과를 얻으며, 설계 조건과 측정 결과를 함께 검토하는 중요성을 배웠습니다.

최초 시뮬레이션5.79 GHz

BW 230MHz · Gain 8.057dBi

실측6.28 GHz

BW 290MHz · 제작물 측정

조건 반영 재시뮬레이션6.25 GHz

BW 300MHz · Gain 8.415dBi

개인 역할 / 팀 구현

개인 역할은 STM 신호처리와 안테나 설계, 회로 검토입니다. 센서 보드 설계와 PLL·MATLAB 작업을 포함한 전체 시스템은 팀의 협업 결과입니다.

정밀도와 응답 속도

FFT 관측 구간을 늘려 주파수 분해능을 높이는 대신 갱신이 느려지는 절충을 확인했습니다. 송신부 전류가 인가되지 않는 문제에서는 부품과 쇼트 여부를 점검하며 원인 후보를 좁혔습니다.
